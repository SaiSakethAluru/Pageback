# `components/Reader/`

This folder contains the main reading and recap UI.

## Contents

- `ReaderPage.jsx`: orchestrates book loading, position restore, and autosave.
- `RecapFAB.jsx`: floating recap trigger and level progression control.
- `RecapPanel.jsx`: bottom-sheet recap display.
- `RecapLevelIndicator.jsx`: visual indicator for recap depth.

## Notes

- `ReaderPage.jsx` coordinates both the reader implementation and the recap overlay.
