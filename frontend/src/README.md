# `src/`

This folder contains the frontend application source code.

## Contents

- `App.jsx`: top-level route configuration.
- `main.jsx`: application entry point.
- `components/`: page and UI components grouped by feature area.
- `readers/`: book-reader implementations and reader selection logic.
- `services/`: API wrappers and Supabase client setup.

## Notes

- Routing is handled in `App.jsx`.
- Shared integrations live under `services/`.
